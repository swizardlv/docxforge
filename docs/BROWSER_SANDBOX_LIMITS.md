# 浏览器安全沙箱限制与图片导入说明

## 1. 浏览器的安全沙箱限制（Web 模式）

当在**纯 Web 浏览器**（如 Chrome、Safari 打开 `http://localhost:5173`）中使用导入功能时：

1. **隐私隔离**：当你在网页中单选导入一个 `document.md` 时，浏览器出于安全策略，仅允许网页读取该 `.md` 文件本身的文本内容。
2. **无法任意读取客户端磁盘**：网页中的前端 JavaScript 代码**无法**自由读取你电脑上未被选择的其他本地文件。因此，如果 `document.md` 中写了相对路径 `![图片](./images/architecture.png)`，浏览器前端是**无法**自动从你的本地硬盘读取 `./images/architecture.png` 并发送给网页的。

---

## 2. 不同模式下的实际可用情况

| 运行/部署模式 | 本地相对/绝对路径图片 | Base64 内嵌图片 | 网络 HTTP(S) 图片 |
| --- | --- | --- | --- |
| **纯 Web 浏览器 (远程部署)** | ❌ 受限于浏览器沙箱，无法跨目录读取客户端磁盘图片 | ✅ 支持（图片数据已写在 md 文本内） | ✅ 支持（后端直接拉取） |
| **同机运行 (API 运行在 localhost)** | ✅ 支持（同机运行的 FastAPI 后端直接读取本机磁盘路径） | ✅ 支持 | ✅ 支持 |
| **Tauri 桌面客户端模式 (Local-First)** | ✅ 支持（桌面端容器拥有完整本地文件访问权限） | ✅ 支持 | ✅ 支持 |

---

## 3. Web 模式下的最佳实践建议

若在纯 Web 界面上使用，建议采用以下方式之一：
1. **使用 Base64 图片**：将图片以 `data:image/png;base64,...` 形式嵌入 Markdown 文件中。
2. **同机运行模式**：在本地运行 FastAPI 后端（`localhost:8000`），并在“图片基准目录”中填写本地绝对路径，同机后端会直接读取本机磁盘图片。
3. **打包文件上传**：后续扩展支持上传包含 `.md` 和 `images/` 文件夹的 `.zip` 压缩包。
