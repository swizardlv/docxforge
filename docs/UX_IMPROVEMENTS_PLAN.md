# 体验升级：项目文件夹一键导入与截图粘贴实现报告

## 1. 方案体验亮点

1. **📂 导入项目文件夹（含图片）**：
   - 允许用户在 Web 页面直接选择/拖入包含 `.md` 文件和 `images/` 子文件夹的项目根目录。
   - 网页自动解析文件夹内的图片，并将 Markdown 中引用的相对路径图片（如 `./images/arch.png`）无缝绑定为内嵌 Data URI。
   - **效果**：用户**无需配置任何路径、无需手动转 Base64**，即可完成包含图片的 Markdown 完整渲染！

2. **📋 剪贴板图片直接粘贴 (`Cmd+V` / `Ctrl+V`)**：
   - 监听编辑器粘贴事件，截图后在 Markdown 编辑器中直接按 `Cmd+V` 即可自动转化为图片节点嵌入到光标所在位置。
