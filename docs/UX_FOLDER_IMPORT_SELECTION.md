# 方案一确认与交互打磨报告：项目文件夹一键导入

## 1. 确认选定方案

选定 **方案一：项目文件夹一键导入（含图片）** 作为核心推荐图片导入交互方式。

### 核心亮点：
1. **零路径配置**：用户无需手动输入任何本地路径，亦无需提前手动转换 Base64。
2. **文件夹级关联**：选择包含 `.md` 及图片资源子文件夹（如 `images/`）的项目目录，系统自动匹配并嵌入 Markdown 中引用的相对图片。
3. **支持全域拖拽**：支持将电脑中的文件夹直接拖入 Markdown 编辑框一键完成加载。

---

## 2. 交互与细节打磨

- **拖拽体验 (Drag & Drop)**：为编辑器增加 Drag & Drop 事件，当用户将文件夹拖入编辑器时，高亮显示拖拽区并自动解析文件夹树。
- **界面按钮突显**：在 Markdown 编辑器顶栏配置醒目的“📂 导入 Markdown 项目文件夹”主按钮。
- **数据处理**：前端自动递归读取 `.md` 及其关联图片，替换为内嵌 Data URI 数据，提交给后端进行标书 Word 渲染。

---
