# 文件夹导入二次弹窗消除与浏览器授权行为说明

## 1. 二次弹窗原因诊断与修复

### 问题原因
先前在触发逻辑中包含了“优先 `showDirectoryPicker()` -> 失败后回退 `folderInputRef.click()`”的二阶段逻辑。如果在某种环境下触发了回退，就会导致浏览器连续弹出两次选择窗口（先弹目录，再弹选择框）。

### 修复措施
统一简化为单一确定性的 `<input type="file" webkitdirectory multiple>` 原生唤起机制：
- 确保用户在点击“📂 导入项目文件夹”时，**100% 只弹出一个操作系统目录选择框**，彻底移除了二次弹窗。

---

## 2. Chrome 浏览器提示“上传 (Upload)”按钮说明

当在 Chrome / Edge 中导入文件夹时，浏览器原生的对话框右下角会显示为 **“上传”**（例如：“是否要上传 'my-folder' 到该网站？包含 5 个文件”）：
- **这是 Chrome 浏览器的标准授权提示机制**：因为选择整个文件夹涉及对目录内文件的批量读取权限，Chrome 统一定义该按钮文案为“上传”。
- **数据安全保障**：DocXForge 采用本地优先（Local-First）架构，即使浏览器提示“上传”，文件也是在你的本地浏览器内存与同机沙箱中解析，数据无需离开你的电脑。
