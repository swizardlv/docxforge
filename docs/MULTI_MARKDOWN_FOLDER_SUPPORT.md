# 多 Markdown 文件文件夹导入支持实现报告

## 1. 实现特性

1. **自动自然序合并 (Natural Sort Order)**：
   - 导入文件夹中若存在多个 `.md` 文件（例如 `01-概述.md`、`02-架构.md`、`03-实施.md`），系统会自动按照自然路径排序并按顺序拼接为完整的 Word 标书正文。
2. **多 Markdown 文件选择器**：
   - 界面上动态感知检测到的所有 Markdown 文件，并提供下拉选择控件。用户可在“✨ 自动按顺序合并所有文件”与“单独查看/编辑具体某个章节文件”之间无缝切换。
3. **全局图片自动绑定**：
   - 无论选择单个文件还是合并全量文件，文件夹内所有的本地图片关联均保持有效并无缝嵌入。
